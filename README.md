# מנלן לאוצר

כלי עזר חינמי ל**אוצר החכמה** (Windows): שדה חיפוש קטן שנפתח בקיצור מקשים מכל מקום במחשב, וכפתורים בתוך וורד.

> **גרסה 0.2.4.** יתכנו באגים, ואשמח לדיווחים ב-Issues.

> **הבהרה:** זו תוכנה עצמאית ולא רשמית. היא אינה קשורה לאוצר החכמה או לחברה שמפיצה אותה, ואינה כוללת את התוכנה או את הספרייה שלה. כדי להשתמש בה צריך אוצר החכמה מותקנת ברישיון תקף.

## איך זה עובד

התוכנה מביאה את אוצר החכמה לקדמת המסך ושולחת לה את הטקסט, כמו שהיית עושה בעצמך: מקש קיצור (F2 או Ctrl+F), הדבקה ו-Enter. אין לה ממשק רשמי לתוכנה, ולכן היא **לא יכולה לדעת אם הפעולה הצליחה**, ועדכון של אוצר החכמה עלול לשנות את ההתנהגות.

## מה היא עושה

- **שדה קטן:** קיצור אחד, ברירת מחדל Alt+X, פותח אותו במצב האחרון. Tab מחליף בין עיון (F2: שם ספר או מחבר) לחיפוש בספרים (Ctrl+F). כותבים, לוחצים Enter, Esc סוגר. אם אוצר החכמה סגורה, היא נפתחת לבד.
- **חיפוש מתקדם:** בחיפוש בספרים יש כפתור "חיפוש מתקדם" שפותח לוח עם האפשרויות של אוצר החכמה. כמו ההצמדה, הסימון רק כותב את הקוד בשורת החיפוש (אפשר גם להקליד אותו ידנית), ואין התערבות בתוך אוצר החכמה. האפשרויות: לפי סדר מילים (`&` בתחילת השורה), תיקוני OCR (`#` בתחילת השורה), כתיב מלא וחסר (`@` לפני כל מילה), מרחק בין מילים (`{10}` בין שתי מילים, ברירת מחדל 30), שלילת מילה (`--` לפני המילה, בכתיבה בתיבה או בלחיצה על מילה מהשורה) השלמת מילה (בוחרים מילה, מוסיפים בתוכה `*` `?` `!` במקום המתאים ולוחצים "החל") ומילים חילופיות (בוחרים מילה וכותבים לה חלופה, למשל "ארבעה קבין" עם ד' וקבים נשלח כ-`(ארבעה/ד') (קבין/קבים)`; אפשר כמה חלופות לאותה מילה, ולחיצה על חלופה מסירה אותה). כמו באוצר החכמה, החלופות לא מופיעות בשורה אלא נשלחות עם החיפוש, ומתחת מוצג מה יישלח. תיבת הסימון "הסתר את החלופות מהשורה" מאפשרת להציג אותן בשורה במקום. כל האפשרויות מוצגות זו מתחת לזו בלוח שנגלל.
- **הצמדת מילים ואותיות שימוש:** בחיפוש בספרים יש שתי תיבות סימון, כמו באוצר החכמה. הסימון כותב את הסימנים ישר בשורת החיפוש, כאילו הקלדת אותם בעצמך: מקף בין מילים מוצמדות ו-+ לפני מילה עם אותיות שימוש (כששניהם חלים על אותה מילה, המקף קודם: רחם-+נא). אפשר לסמן את כל המילים, או כל מילה בנפרד דרך החץ.
- **רשימת ספרים תוך כדי הקלדה (אופציונלי, כבוי כברירת מחדל):** בעיון (שם ספר או מחבר) אפשר להציג בזמן ההקלדה רשימת ספרים רלוונטיים, עם שם הספר והמחבר. הרשימה היא לתצוגה בלבד: בחירה בספר ממלאת את שמו בשורה, ושום דבר לא נשלח עד ש־Enter נלחץ. היא נארזת בתוכנה כתמונת מצב כללית של הקטלוג, ולכן אינה בהכרח מה שמותקן אצלכם (בכל גרסה וחבילה יש ספרים אחרים), והיא אינה מחפשת בתוך אוצר החכמה. מפעילים ומכבים במתג בשדה הקטן או בהגדרות.
- **היסטוריית חיפושים:** כפתור 🕘 בשדה הקטן מציג את החיפושים האחרונים (עיון וחיפוש), עם שעה שאפשר להסתיר בהגדרות. לחיצה על חיפוש ממלאת אותו בשדה.
- **העתקה אוטומטית של הסימון:** מסמנים טקסט בכל תוכנה, לוחצים על הקיצור, והטקסט כבר בשדה, בלי Ctrl+C. אפשר לכבות בהגדרות.
- **כפתורים בוורד (תוסף אופציונלי נפרד):** עיון וחיפוש בספרים. מי שרוצה מוריד את `MenalanOtzar-Word-<גרסה>.zip` מדף [Releases](../../releases). ראה [הוראות](word/INSTALL-WORD.md).
- אנימציית פתיחה עם הלוגו בכל פתיחה של החלון הראשי, שש ערכות צבעים (כולל אחת בצבעי אוצר החכמה), וקיצורים שאפשר לשנות.

## דרישות

- Windows 10 או 11.
- אוצר החכמה מותקנת (`otzar.exe`).

## התקנה

1. הורד את `Menalan-Otzar-Setup-<גרסה>.exe` מדף [Releases](../../releases) והתקן.
2. התוכנה רצה ברקע ליד השעון. לחיצה על הסמל פותחת את ההגדרות.

## אם משהו לא עובד

- **הטקסט לא נכנס לשדה הנכון:** בהגדרות יש "שנה נקודת לחיצה". היא קובעת על איזה מקום ריק בחלון אוצר החכמה התוכנה לוחצת לפני הקיצור.
- **קיצור לא פותח כלום:** בהגדרות מופיע ✖ ליד קיצור תפוס. בחר קיצור אחר.
- **התוכנה פועלת רק מול `otzar.exe`**, לא מול אוצריא או תוכנות אחרות.
- **יומן טכני:** `%TEMP%\menalan-otzar.log`.

## בנייה מהקוד

דרוש Node.js 18 ומעלה.

```bash
npm install
npm start          # הרצה לבדיקה
npm run build      # בניית קובץ התקנה לתיקיית dist
```

או לחיצה כפולה על `build.bat` (מבקש הרשאת מנהל).

## English summary

**Menalan Otzar** (מנלן לאוצר) is a free, unofficial Windows helper for the Otzar HaChochma desktop program: a global-hotkey search box (default Alt+X, Tab switches between lookup and search), auto-copy of selected text from any app, and optional ribbon buttons for Microsoft Word (see [word/INSTALL-WORD.md](word/INSTALL-WORD.md), Hebrew).

It works by sending keystrokes to `otzar.exe`, so it cannot confirm that an action succeeded. It is not affiliated with Otzar HaChochma and does not include it. Version 0.2.4 is an early release.
