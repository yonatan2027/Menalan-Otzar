# מְנָלָן לאוצר (Menalan Otzar)

**כלי עזר מתקדם למשתמשי תוכנת אוצר החכמה**

מנלן לאוצר הוא כלי עזר חינמי למשתמשי תוכנת אוצר החכמה, המיועד להפוך את העבודה עם המאגר למהירה, נוחה ויעילה יותר באמצעות קיצורי מקשים.

## מה מציעה מנלן?

- **חיפוש מהיר:** שדה חיפוש נגיש מכל תוכנה באמצעות קיצור המקשים `Alt + X`.
- **מעבר בין מצבי חיפוש:** מעבר בין עיון בספרים לחיפוש חופשי באמצעות `Tab`.
- **היסטוריית חיפושים:** גישה נוחה לחיפושים האחרונים.
- **העתקה אוטומטית:** העברת טקסט מסומן לשדה החיפוש.
- **פתיחה אוטומטית:** הפעלת תוכנת אוצר החכמה בעת הצורך.
- **התאמה אישית:** קיצורי מקשים, ערכות צבעים והגדרות נוספות.
- **תוסף Microsoft Word:** תמיכה אופציונלית בכפתורים בתוך Word (תוסף נפרד).

## דרישות מערכת

- Windows 10 או Windows 11.
- תוכנת אוצר החכמה מותקנת במחשב ברישיון תקף.

## הבהרה

מנלן לאוצר היא תוכנת עזר עצמאית ולא רשמית. היא אינה קשורה למפתחי תוכנת אוצר החכמה ואינה כוללת את תוכנת אוצר החכמה עצמה.

התוכנה פועלת באמצעות שליחת פעולות מקלדת לתוכנת אוצר החכמה, ולכן אינה יכולה לאמת את הצלחת הפעולה. עדכונים בתוכנת אוצר החכמה עשויים להשפיע על התאימות.
